В Ansible понятие «типы переменных» обычно разделяют на две большие категории: **по источнику и области видимости** (где и как они определяются) и **по типу данных** (какие значения они хранят в формате YAML).

Ниже приведен подробный разбор обеих категорий.

---

### 1. Типы переменных по источнику и области видимости
В Ansible существует строгая иерархия приоритетов переменных (Variable Precedence). Вот основные типы по месту их объявления:

*   **Extra Variables (Переменные командной строки):** Задаются при запуске через флаг `-e` или `--extra-vars` (например, `ansible-playbook site.yml -e "my_var=value"`). **Имеют наивысший приоритет** и перезаписывают любые другие переменные.
*   **Inventory Variables (Переменные инвентаря):** 
    *   `host_vars` — переменные для конкретного хоста.
    *   `group_vars` — переменные для группы хостов.
*   **Playbook Variables (Переменные плейбука):** Определяются в блоке `vars:` на уровне всего `play` (игры).
*   **Task Variables (Переменные задачи):** Определяются в блоке `vars:` внутри конкретной `task` (задачи). Действуют только для этой задачи.
*   **Role Variables (Переменные ролей):**
    *   `roles/my_role/defaults/main.yml` — значения по умолчанию (очень низкий приоритет, легко переопределить).
    *   `roles/my_role/vars/main.yml` — основные переменные роли (высокий приоритет).
*   **Registered Variables (Зарегистрированные переменные):** Создаются динамически во время выполнения плейбука с помощью директивы `register:`. Сохраняют в переменную результат выполнения задачи (вывод, статус, код возврата).
*   **Facts (Факты):** Это переменные, которые Ansible автоматически собирает с целевых хостов перед выполнением задач (с помощью модуля `setup`). Примеры: `ansible_os_family`, `ansible_default_ipv4.address`, `ansible_hostname`.
*   **Magic Variables (Магические переменные):** Внутренние переменные самого Ansible, которые отражают состояние инвентаря и выполнения. Примеры:
    *   `hostvars` — словарь со всеми переменными всех хостов.
    *   `groups` — список всех групп из инвентаря.
    *   `group_names` — группы, к которым принадлежит текущий хост.
    *   `inventory_hostname` — имя текущего хоста в инвентаре.
*   **Vault Variables (Зашифрованные переменные):** Переменные, хранящие конфиденциальные данные (пароли, ключи), зашифрованные с помощью `ansible-vault`.
*   **Включаемые переменные (Include vars):** Переменные, подгружаемые динамически из внешних файлов с помощью модуля `include_vars` или `vars_files`.

### 2. Типы переменных по типу данных (YAML)
Поскольку Ansible использует YAML для конфигурации, типы данных переменных соответствуют стандартам YAML:

*   **Строки (Strings):** Текстовые значения. Могут быть в кавычках или без них (например, `"Hello World"`, `my_string`).
*   **Числа (Integers / Floats):** Целые и дробные числа (например, `port: 8080`, `timeout: 3.14`).
*   **Булевы значения (Booleans):** Логические `true` / `false`. В YAML также можно писать `yes` / `no`, `on` / `off` (но в современном Ansible рекомендуется использовать именно `true`/`false` для избежания путаницы со строками).
*   **Списки (Lists / Arrays):** Упорядоченные наборы элементов.
    ```yaml
    my_list:
      - apple
      - banana
      - cherry
    # или в одну строку: my_list: ["apple", "banana", "cherry"]
    ```
*   **Словари (Dictionaries / Hashes / Maps):** Неупорядоченные пары «ключ-значение».
    ```yaml
    my_dict:
      user: admin
      role: superuser
    ```
*   **Null / None:** Пустое значение, обозначающее отсутствие данных (например, `my_var: null` или просто `my_var:`).
