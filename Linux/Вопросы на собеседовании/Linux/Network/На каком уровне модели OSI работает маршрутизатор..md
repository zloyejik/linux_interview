Маршрутизатор (роутер) работает на третьем (сетевом) уровне модели OSI (Open Systems Interconnection).
Краткие подробности:
Сетевой уровень (Layer 3) отвечает за логическую адресацию (например, IP-адреса) и определение оптимального пути для передачи данных между разными сетями.
Маршрутизатор анализирует заголовки сетевых пакетов (например, IP-пакетов), чтобы принять решение о том, куда направить данные дальше.
Для сравнения: коммутатор (свич) обычно работает на втором (канальном) уровне, оперируя MAC-адресами в пределах одной локальной сети, а маршрутизатор соединяет разные сети между собой.
