FSMO (Flexible Single-Master Operations) — это ==специальные уникальные роли контроллеров домена в [Active Directory](https://ru.wikipedia.org/wiki/FSMO), которые могут выполняться только одним сервером одновременно для предотвращения конфликтов в базе данных==. 

## Виды ролей FSMO

Всего существует 5 основных ролей, разделенных на два уровня:

- Уровня леса (единственные на всю структуру):
    
    - Хозяин схемы (Schema Master) — отвечает за любые изменения схемы данных Active Directory.
    - Хозяин именования доменов (Domain Naming Master) — добавляет или удаляет домены из леса. 
    
- Уровня домена (по одной на каждый отдельный домен):
    
    - Эмулятор PDC (PDC Emulator) — обрабатывает старые запросы входа, синхронизирует время и управляет блокировками учетных записей.
    - Хозяин RID (RID Master) — выдает пулы уникальных номеров (RID) для создания новых пользователей и компьютеров.
    - Хозяин инфраструктуры (Infrastructure Master) — обновляет ссылки на объекты между разными доменами. 
    

Чтобы посмотреть текущих владельцев ролей FSMO в Samba Active Directory DC, выполните основную встроенную команду на самом контроллере домена: [1]

```bash
samba-tool fsmo show
```

## Пример вывода

Команда покажет владельцев для всех 7 ролей (5 стандартных + 2 роли зон DNS): [2, 3]

Вывод команды отображает список владельцев (например, `CN=NTDS Settings,CN=DC1...`) для каждой из семи ролей FSMO: SchemaMaster, InfrastructureMaster, RidAllocationMaster, PdcEmulationMaster, DomainNamingMaster, DomainDnsZonesMaster и ForestDnsZonesMaster. Полный пример вывода можно найти в документации. [2, 3]

## Полезные смежные команды

Если вам также нужно управлять этими ролями через `samba-tool`: [4]

1. Штатная передача роли (`transfer`) на текущий сервер:
    
    ```bash
    samba-tool fsmo transfer --role=pdc
    ```
    
    _(Вместо `pdc` можно указать `rid`, `schema`, `naming`, `infrastructure`, `domaindns`, `forestdns` или `all`)_
2. Принудительный захват (`seize`) при аварии:
    
    ```bash
    samba-tool fsmo seize --role=rid
    ```
    
    _Используется только в случае, если старый владелец роли полностью уничтожен и больше никогда не включится в сети._
