ACE (Access Control Entry) — запись в списке управления доступом.  
ACL (Access Control List) — список управления доступом.  
AD, AD DS (Active Directory, Active Directory Domain Services) — служба катало-

гов (СК) для операционных систем Microsoft Windows Server.  
ADMX (Administrative Template Xml-Based) — формат XML-файла с администра-

тивным шаблоном для объектов групповых политик (см. GPO).  
BIND (Berkeley Internet Name Domain) — сервер доменных имен, DNS-сервер. CN (Common Name) — общее имя объекта Active Directory, часть DN.  
СSE (Client Side Extensions) — клиентские расширения для применения групповых

политик в домене.  
DACL (Discretionary Access Control List) — список управления дополнительным

доступом.  
DC (Domain Controller) — контроллер домена (КД).  
DHCP (Dynamic Host Configuration Protocol) — протокол динамической настройки

узла.  
DN (Distinguished Name) — уникальное составное имя объекта Active Directory,

формат идентификатора объекта GPO.  
DNS (Domain Name System) — система доменных имен.  
DRS (Directory Replication Services) — службы репликации каталога (см. AD). DS (Directory Services, Domain Services) — службы каталогов (см. AD).  
DSA (Directory System Agent) — агент системы каталогов.  
GID, (Primary) Group ID — числовой идентификатор (основной) группы пользова-

теля.  
gMSA (group Managed Service Account) — групповая управляемая учётная запись

службы.  
GPO (Group Policy Object) — объект групповой политики.  
GUID (Globally Unique Identifier) — глобальный уникальный идентификатор,

назначенный службами домена Active Directory при создании экземпляра объекта. Представляет собой 128-разрядное число.

FSMO (Flexible Single Master Operations) — операции с одним исполнителем.

KCC (Knowledge Consistency Checker) — средство проверки согласованности дан- ных; компонент в Active Directory, который генерирует топологию репликации между контроллерами домена.

LDAP (Lightweight Directory Access Protocol) — облегченный протокол доступа к каталогам.

LDB (Lightweight Database) — легковесная база данных.  
NC (Naming Context) — раздел каталога.  
NIS (Network Information Services) — служба сетевой информации.  
NSS (Name Service Switch) — диспетчер службы имен.  
NTDS (NT Directory Services) — службы каталогов Windows NT, см. AD. OU (Organizational Unit) — подразделение, организационная единица. PDC (Primary Domain Controller) — основной контроллер домена.  
PID (Process Identifier) — уникальный идентификатор процесса.  
PSO (Password Settings Object) — политика паролей.
RDN (Relative Distinguished Name) — составная часть DN.

RODC (Read-Only Domain Controller) — контроллер домена с копией базы данных каталога, которая доступна только для чтения.

RPC (Remote Procedure Call) — удаленный вызов процедур, технология работы программ.

SACL (System Access Control List) — список контроля доступа к системе.  
SAM (Security Account Manager) — диспетчер безопасности учетных записей. SID (Security Identifier) — идентификатор безопасности.  
SPN (Sevice Principal Name) — идентификатор экземпляра службы (сервиса). SSSD (System Security Services Daemon) — сервис для управления аутентифика-

цией и авторизацией в операционных системах на базе Linux, который служит для подключения к AD.

UID (User ID) — уникальный числовой идентификатор пользователя.

UPN (User Principal Name) — имя пользователя для входа в формате адреса электронной почты.

БД (База Данных) — см. также LDB. КД (Контроллер Домена) — см. DC. СК (Служба Каталогов) — см. AD.
