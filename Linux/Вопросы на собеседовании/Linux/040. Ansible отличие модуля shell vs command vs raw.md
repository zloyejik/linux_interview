### Краткое сравнение

| Модуль | Оболочка | Пайпы (`\|`) | Редиректы (`>`) | Переменные (`$VAR`) | Безопасность |
|--------|----------|--------------|-----------------|---------------------|--------------|
| **`raw`** | Нет (прямой SSH) | ✅ | ✅ | ✅ | ❌ Низкая |
| **`command`** | Нет | ❌ | ❌ | ❌ | ✅ Высокая |
| **`shell`** | `/bin/sh` | ✅ | ✅ | ✅ | ⚠️ Средняя |

---

### 1. `raw` — Прямая SSH-команда

**Что делает:** Выполняет команду напрямую через SSH, **без участия Ansible**. Ansible просто отправляет строку на удаленный хост и возвращает вывод.

**Особенности:**
- Не требует Python на целевом хосте
- Не собирает `facts` (информацию о системе)
- Не поддерживает `become` (sudo) в некоторых случаях
- Не проверяет синтаксис команды
- Нет защиты от инъекций

**Когда использовать:**
- На хостах без Python (например, сетевое оборудование, старые системы)
- Установка Python на целевой хост
- Экстренные случаи, когда другие модули не работают

**Пример:**
```yaml
- name: Установить Python на хост без него
  raw: apt-get update && apt-get install -y python3
```

---

### 2. `command` — Безопасный, но ограниченный

**Что делает:** Выполняет команду **без оболочки**. Ansible напрямую запускает исполняемый файл с аргументами.

**Особенности:**
- ✅ Безопасен: нет риска инъекций через shell
- ✅ Поддерживает `chdir`, `creates`, `removes` для идемпотентности
- ❌ Нет пайпов (`|`), редиректов (`>`, `<`), переменных окружения (`$VAR`)
- ❌ Нет `&&`, `||`, `;` (цепочки команд)
- ❌ Нет globbing (`*`, `?`)

**Когда использовать:**
- Когда нужна простая команда без shell-синтаксиса
- Когда важна безопасность и предсказуемость
- Когда можно использовать встроенные параметры для идемпотентности

**Пример:**
```yaml
- name: Создать файл, если его нет
  command: touch /tmp/testfile
  args:
    creates: /tmp/testfile  # Идемпотентность: не выполнится, если файл уже есть

- name: Запустить скрипт
  command: /usr/local/bin/myscript.sh
  args:
    chdir: /opt/app  # Выполнить из этой директории
```

**Ошибка (не сработает):**
```yaml
- name: Это НЕ сработает!
  command: echo "Hello" > /tmp/test.txt  # Редирект не поддерживается
```

### 3. `shell` — Полноценная оболочка

**Что делает:** Выполняет команду через оболочку (`/bin/sh` по умолчанию). Поддерживает весь синтаксис shell.

**Особенности:**
- ✅ Поддерживает пайпы, редиректы, переменные, `&&`, `||`, `;`
- ✅ Поддерживает `executable` для выбора оболочки (`/bin/bash`, `/bin/zsh`)
- ⚠️ Менее безопасен: возможна инъекция команд
- ⚠️ Менее предсказуем: зависит от настроек оболочки

**Когда использовать:**
- Когда нужны пайпы, редиректы, переменные окружения
- Когда нужны цепочки команд (`&&`, `||`)
- Когда нужен специфичный синтаксис bash (например, `**` для рекурсивного glob)

**Пример:**
```yaml
- name: Пайп и редирект
  shell: cat /var/log/syslog | grep ERROR > /tmp/errors.txt

- name: Цепочка команд
  shell: apt-get update && apt-get install -y nginx

- name: Переменные окружения
  shell: echo "User is $USER"

- name: Использовать bash вместо sh
  shell: |
    for i in {1..5}; do
      echo "Count: $i"
    done
  args:
    executable: /bin/bash
```

### Рекомендации по использованию

#### ✅ Используйте `command`, когда:
- Команда простая и не требует shell-синтаксиса
- Важна безопасность
- Можно использовать `creates`/`removes` для идемпотентности

```yaml
- name: Перезапустить сервис
  command: systemctl restart nginx
```

#### ✅ Используйте `shell`, когда:
- Нужны пайпы, редиректы, переменные
- Нужны цепочки команд
- Нужен специфичный синтаксис bash

```yaml
- name: Найти и удалить старые логи
  shell: find /var/log -name "*.log" -mtime +30 -delete
```

#### ✅ Используйте `raw`, когда:
- На хосте нет Python
- Устанавливаете Python или Ansible
- Экстренная ситуация, другие модули не работают

```yaml
- name: Установить Python
  raw: yum install -y python3
```

#### ❌ Избегайте `raw` для обычных задач:
```yaml
# ПЛОХО: Используйте command или shell вместо raw
- name: Создать файл
  raw: touch /tmp/test.txt  # Нет идемпотентности, небезопасно
```

### Практические примеры

#### Пример 1: Безопасная установка пакета
```yaml
- name: Установить nginx (идемпотентно)
  command: apt-get install -y nginx
  args:
    creates: /usr/sbin/nginx  # Не выполнится, если nginx уже установлен
```

#### Пример 2: Обработка вывода с пайпами
```yaml
- name: Подсчитать количество процессов
  shell: ps aux | grep nginx | wc -l
  register: nginx_count

- debug:
    msg: "Nginx процессов: {{ nginx_count.stdout }}"
```

#### Пример 3: Инициализация хоста без Python
```yaml
- name: Установить Python на новый хост
  raw: |
    apt-get update
    apt-get install -y python3

- name: Теперь можно использовать обычные модули
  command: hostname
```

---

### Чек-лист

1. **По умолчанию используйте `command`** — он безопаснее и предсказуемее.
2. **Переключайтесь на `shell`**, если нужны пайпы, редиректы или цепочки команд.
3. **Используйте `raw` только** когда на хосте нет Python или в экстренных случаях.
4. **Добавляйте `creates`/`removes`** для идемпотентности (работает в `command` и `shell`).
5. **Избегайте `raw` для регулярных задач** — он обходит механизмы Ansible.

Эти правила помогут вам писать надежные и безопасные Ansible-плейбуки.
