Короткий ответ: **сам по себе Bash не умеет парсить JSON**, так как это просто командная оболочка для работы с текстом и процессами. 

Пытаться парсить JSON с помощью `grep`, `sed` или `awk` — это **антипаттерн**. Такой код сломается при первом же изменении формата (появятся пробелы, переносы строк или вложенные объекты).

В экосистеме Linux есть золотой стандарт для этой задачи — утилита **`jq`**. Если `jq` нет в системе, используют однострочники на **Python**.

Разберем оба подхода.

---

### Способ 1. Утилита `jq` (Правильный и единственный разумный путь)

`jq` — это `sed`/`awk` для JSON. Она читает JSON, применяет к нему фильтры и выводит результат.

**Установка:**
```bash
sudo apt install jq      # Debian/Ubuntu
sudo yum install jq      # CentOS/RHEL
brew install jq          # macOS
```

Допустим, у нас есть JSON в переменной:
```bash
JSON='{"user": {"name": "Alice", "age": 30, "roles": ["admin", "user"]}, "active": true}'
```

#### 1. Извлечение простых значений
```bash
echo "$JSON" | jq '.user.name'
# Вывод: "Alice" (обратите внимание на кавычки!)

# Чтобы получить "сырой" текст без кавычек (критично для bash-переменных), используйте флаг -r:
echo "$JSON" | jq -r '.user.name'
# Вывод: Alice
```

#### 2. Сохранение результата в переменную Bash
```bash
NAME=$(echo "$JSON" | jq -r '.user.name')
echo "Привет, $NAME"
```

#### 3. Работа с массивами
```bash
# Получить первый элемент массива
echo "$JSON" | jq -r '.user.roles[0]' 
# Вывод: admin

# Пройти циклом по всем элементам массива
echo "$JSON" | jq -r '.user.roles[]'
# Вывод:
# admin
# user
```

#### 4. Фильтрация и условия (Суперсила `jq`)
Допустим, у нас есть массив пользователей:
```bash
USERS='[{"name":"Bob","age":17}, {"name":"Alice","age":25}, {"name":"Charlie","age":30}]'
```

Найти имена только совершеннолетних:
```bash
echo "$USERS" | jq -r '.[] | select(.age >= 18) | .name'
# Вывод:
# Alice
# Charlie
```

#### 5. Обработка отсутствующих ключей и `null`
Если ключа нет, `jq` вернет `null`. В Bash это превратится в строку `"null"`, что может сломать логику. Используйте оператор `//` для дефолтного значения:
```bash
echo "$JSON" | jq -r '.user.email // "email не указан"'
```

#### 6. Практический пример: `curl` + `jq`
Получить информацию о пользователе GitHub и вытащить URL его аватара:
```bash
AVATAR_URL=$(curl -s https://api.github.com/users/torvalds | jq -r '.avatar_url')
echo "Аватар Линуса: $AVATAR_URL"
```

### Способ 2. Python (Если `jq` нельзя установить)

Если вы пишете скрипт для Docker-контейнера на основе `alpine` или `distroless`, где нет `jq` и нет пакетного менеджера, но есть Python (или Node.js), используйте однострочники.

**Python 3:**
```bash
NAME=$(echo "$JSON" | python3 -c "import sys, json; print(json.load(sys.stdin)['user']['name'])")
```
*Плюс:* Python есть почти везде.
*Минус:* Громоздкий синтаксис, падает с трейсбеком, если JSON невалиден или ключа нет (нужно писать `.get('user', {}).get('name', 'default')`).

---

### Способ 3. `grep` / `sed` (Темная сторона. Только для самых простых случаев)

**Почему так делать не надо:** Если JSON придет в одну строку, или в нем будут вложенные ключи с одинаковыми именами, или значения будут экранированы — ваш парсинг сломается.

Используйте это **только** если вам нужно вытащить одно простое значение из гарантированно простого и плоского JSON, и у вас нет никаких других инструментов.

```bash
# Извлечь значение ключа "name"
NAME=$(echo "$JSON" | grep -o '"name" *: *"[^"]*"' | cut -d'"' -f4)
```

### Чек-лист для Bash-скриптов, работающих с JSON

1. **Всегда проверяйте валидность JSON.** Если API вернул HTML (например, страницу ошибки 502 от Nginx), `jq` упадет.
   ```bash
   RESPONSE=$(curl -s https://api.example.com/data)
   
   # Проверяем, что это валидный JSON
   if ! echo "$RESPONSE" | jq empty 2>/dev/null; then
       echo "Ошибка: API вернул не JSON!"
       exit 1
   fi
   
   # Дальше парсим
   ```
2. **Используйте `set -e`** в начале скрипта, чтобы он прерывался при ошибках, либо явно проверяйте `$?` после вызова `jq`.
3. **Для сложных преобразований** (например, собрать JSON из переменных Bash) используйте `jq -n`:
   ```bash
   MY_VAR="test"
   # Собираем новый JSON
   NEW_JSON=$(jq -n --arg v "$MY_VAR" '{my_key: $v}')
   echo "$NEW_JSON"
   # Вывод: { "my_key": "test" }
   ```
   *Это избавит вас от необходимости вручную экранировать кавычки и спецсимволы в значениях переменных.*
